# Work Board: шаблон настольного приложения

Архитектура согласована пользователем 23 октября 2026 года. Реализация выполняется в текущем проекте.

## Назначение и границы

Подготовить запускаемый шаблон по архитектуре Matrix: Node.js, Electron, Vue 3,
Vite, Pinia, Vue Router, Tailwind CSS и Lucide. JavaScript, ESM и Composition API.
Приложение работает локально. В поставке нет HTTP-сервера, gRPC, сертификатов,
авторизации, поиска Matrix, предметных таблиц, CRUD и демонстрационных записей.
Vite используется только во время разработки; собранный клиент открывает локальный HTML.

## Архитектура

`renderer component → Pinia/composable → renderer service → desktopApi → preload → IPC handler → main service/repository → SQLite`.

- `src/main`: lifecycle, окно, IPC, сервисы, репозитории и SQLite.
- `src/renderer`: layouts, views, components, stores, composables, services, infrastructure.
- `src/shared`: имена каналов, допустимые настройки и ограниченный preload bridge.
- `src/public`: место для общих ресурсов приложения.
- `build/main/preload.cjs`, `build/renderer`: результат Vite.
- `release`: пакеты electron-builder.

Сохраняются границы Matrix, но сетевой сервис заменяется локальным репозиторием.
Полное копирование Matrix перенесло бы лишние функции; новая архитектура с нуля
нарушила бы требование одинаковой структуры. Используется очищенный каркас.

## Хранилище и безопасность

SQLite через встроенный `node:sqlite` в Electron 38.1.0, как установленном в Matrix.
Без нативных npm-драйверов. Требование к системному Node.js: >=22.13.0.
Версии основных инструментов фиксируются по установленному Matrix.
Файл `work-board.sqlite` лежит в `app.getPath('userData')/data`, вне каталога установки.
Миграции main-процесса используют транзакции и `PRAGMA user_version`.
Единственная стартовая таблица `app_settings` хранит тему, а не предметные данные.
Соединение закрывается при выходе; повторное открытие сохраняет настройки.

В renderer нет Node.js, файловой системы, SQL и произвольного IPC.
Включены `contextIsolation` и `sandbox`. Preload собирается в CommonJS.
Методы bridge перечислены явно; запросы проверяют отправителя и параметры.
Навигация за пределы приложения и новые окна запрещены.

## Интерфейс

Нейтральная оболочка в духе Matrix: боковая панель, верхняя строка, область страницы.
Светлая и тёмная темы, системный Segoe UI, спокойные серые поверхности и зелёный акцент.
Палитра: canvas #f5f5f7, rail #ececef, panel #ffffff, text #2a2c32,
muted #636975, accent #15803d. Отступы 8/12/16/24/32 px.
Без маркетинговых блоков, фальшивых показателей и избыточной анимации.

- `App.vue` подключает layout; layout отвечает за оболочку и bootstrap.
- `AppSidebar` выводит маршруты; принимает `collapsed`, сообщает `toggle`.
- `PageHeading` принимает заголовок и описание.
- `Home.vue`: пустое рабочее пространство без предметных функций.
- `Settings.vue`: выбор темы и реальный статус локального хранилища.
- `Info.vue`: версия и локальный режим работы.
- Pinia хранит общие настройки и статус; `useAppearance` применяет тему к DOM.

## Проверка и поставка

Проверить реальную SQLite во временной папке: создание, повторный запуск,
миграции и валидацию настроек. Проверить ограниченный preload и обработку ошибок.
Собрать renderer и preload. Smoke-проверка Electron должна загрузить собранный
интерфейс и пройти через настоящий preload/IPC/SQLite с изолированным userData.
Подготовить команды dev, start, build, pack:win, build:win и README.
